# Prank eCampus Result

A colorful, harmless result-day prank page built for friends and classmates.

## What it does

- Presents a playful eCampus-style result desk.
- Uses a short suspense animation before revealing the joke.
- Clearly labels itself as `PRANK MODE`.
- Does not send, store, or validate any entered information.
- Works as a static page on GitHub Pages or any basic web server.

## Run locally

Open `index.html` in a browser, or serve the folder with:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Important

This is not an official college result portal. Keep the reveal friendly, never request real passwords, and do not use the page to impersonate a school or collect personal data.
